=== PROMPT 17 ===
Input: Explain the practical difference between a process and a thread.
Time: 9.71s
Output:
1.  A process is a full program in execution; a thread is a slice of that program running inside the same process.
2.  If you spin up a new thread, the OS creates a separate kernel-space process to handle it, saving registers and memory for that slice.
3.  The main process shares its memory with the thread, but the thread has its own execution context (stack, registers, heap) and CPU register state.
4.  Concurrency means: if the main process runs a loop and the thread runs a loop, they execute at different times and on different CPUs, not simultaneously.
5.  The only difference that matters is that the main process runs sequentially, while multiple threads inside it can run in parallel.
